# drewtyl.com

Next.js portfolio site with two views: Recruiter (/) and Brand (/brand).

- Edit all words, links and numbers in `content.ts`
- Put photos in `public/photos/` and your CV at `public/drew-teo-cv.pdf`
- Run locally: `npm install` then `npm run dev` and open http://localhost:3000
- Deploy: push to GitHub, then import the repo on vercel.com
